# Clac - Online Utility Tool

Clac is a lightweight, high-performance online utility tool designed for quick daily calculations and data processing. Built with modern web technologies, it provides a clean, distraction-free user experience with instant client-side processing.

🔗 **Live Demo**: [https://clac.qtool.io/](https://clac.qtool.io/)

## ✨ Features

- ⚡ **Instant Processing**: All computations are handled entirely in the browser with zero server latency.
- 📱 **Fully Responsive**: Seamlessly adapts to desktops, tablets, and mobile devices.
- 🎨 **Clean UI/UX**: Minimalist interface designed for focus and ease of use.
- 🔒 **Privacy First**: No user data is collected or stored; everything stays in your browser.
- 🌙 **Dark Mode Support**: Built-in theme switching for comfortable viewing in any lighting condition.
- ⌨️ **Keyboard Shortcuts**: Power-user friendly shortcuts for faster operation.

## 🛠️ Tech Stack

- **Frontend**: Modern JavaScript (ES6+)
- **Styling**: CSS3 with responsive design patterns
- **Build Tool**: Vite
- **Deployment**: Cloudflare Pages

## 🚀 Getting Started

Follow these steps to run the project locally:

### Prerequisites

- Node.js >= 18.0.0
- npm >= 9.0.0

### Installation & Development

```bash
# Clone the repository
git clone https://github.com/qtoolio/clac-tool.git
cd clac-tool

# Install dependencies
npm install

# Start the development server
npm run dev
